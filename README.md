# Proyecto – Ruby Solitaire 

Implementación en C++ de dos juegos de solitario jugables por consola:
- **Solitario Golf**: 9 rondas, gana quien obtenga menos puntos.
- **Solitario Spider**: completar 8 escaleras (K → A) para eliminar todas las cartas.

Incluye funcionalidad de deshacer y rehacer jugadas, validación de reglas y manejo robusto de entradas.

## Tecnologías
- Lenguaje: C++
- Estructuras de datos lineales implementadas en el curso (listas, colas, pilas).
- Interfaz: consola.
